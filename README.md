Project Overview: Automated Plant Leaf Disease Detection System 🌿 Developed as a Semester V project for the Digital Image Processing (DIP) course at Aror University of Art, Architecture, Design & Heritage, Sukkur 🏛️, this system implements an end-to-end computer vision pipeline to automate the detection and severity quantification of plant leaf diseases 🦠.Manual crop inspection is often subjective and time-consuming. This project applies foundational and advanced DIP algorithms to extract quantitative spatial, color, and textural features from raw digital images, transforming them into reliable diagnostic metrics 📊.Core Digital Image Processing Pipeline & Techniques:Spatial Filtering & Noise Reduction 🛡️: Utilizes median filtering to suppress impulse noise while preserving sharp edge boundaries of the leaf structures.Contrast Enhancement ☀️: Applies histogram equalization on the grayscale intensity channel to normalize illumination variations and enhance local contrast.Color Space Transformation 🎨: Converts input images from the standard $\text{RGB}$ color model to the $\text{HSV}$ (Hue, Saturation, Value) color space, facilitating robust chromaticity-based segmentation separate from lighting intensity.Thresholding & Binary Masking ✂️: Employs Otsu’s Thresholding to compute optimal global thresholds automatically, separating the leaf foreground from complex backgrounds.Morphological Operations 🧹: Utilizes morphological opening and closing (using structural elements and kernels) to eliminate false positives, smooth boundaries, and clear noise artifacts from binary lesion masks.Feature Extraction 📐: Combines statistical color moments (mean and standard deviation in HSV space) with textural feature descriptors extracted via the Gray-Level Co-occurrence Matrix (GLCM)—including contrast, energy, homogeneity, and correlation—alongside pixel-ratio severity calculations 🔍
